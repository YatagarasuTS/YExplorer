Нужен доступ к файлам

YExplorer ищет по именам и содержимому файлов в памяти телефона. Всё работает прямо на устройстве, данные никуда не отправляются.

Где искать

По умолчанию — все локальные диски. Системные папки и мусор исключены (вкладка «Исключения»).

Не индексировать

Имя папки (например node_modules) исключается везде, полный путь — только он.

Что искать

Внутри документов и кода
txt, md, json, исходники, docx, xlsx, pptx, odt, pdf, html и другие.
Текст на скриншотах (OCR)
Распознаёт надписи на png/jpg встроенным в Windows 10/11 движком. Работает в фоне, первый проход идёт дольше.
Прощать опечатки
«докумет» найдёт «документ». Также исправляется раскладка: «ghbdtn» → «привет».
